# Style Conversation Flow Spec

> folio4me 스타일 질의 및 포트폴리오 생성 대화 흐름 명세서

---

## 1. 개요

이 문서는 포트폴리오 콘텐츠 수집 완료 후, 템플릿 스타일을 결정하고 포트폴리오를 생성하는 대화 흐름을 정의합니다.

### 1.1 목적

- 사용자와 AI 간 대화를 통해 포트폴리오 스타일 선호도 수집
- LLM-as-a-Judge 기반 템플릿 추천
- 최종 포트폴리오 생성 및 제공

### 1.2 진입 조건

- `conversation-flow-spec.md`의 Step 11(About) 완료
- `portfolio.json`의 `about.confirmed: true` 상태

### 1.3 데이터 스키마

- 본 문서의 데이터 구조는 `style_data_schema.md` 참조
- 저장 경로: `data/{uuid}/style.json`

### 1.4 관련 문서

- `conversation-flow-spec.md`: 본 흐름 진입 전 완료해야 하는 콘텐츠 수집 흐름
- `style_data_schema.md`: 스타일 선택 데이터 스키마
- `template_schema.md`: 템플릿 구조 및 메타데이터 스키마
- `portfolio-data-schema.md`: 포트폴리오 콘텐츠 스키마 (생성 시 사용)
- `development.md`: 전체 개발 단계 정의 (Phase 2, 3)

## 2. 템플릿 구조

> 상세 스키마는 `template_schema.md` 참조

```
/templates
  ├── 1/
  │   ├── metadata.json       ← 템플릿 메타 정보 (필수)
  │   ├── preview.png         ← 대표 이미지 (필수)
  │   ├── preview.gif         ← 인터랙션 미리보기 (선택)
  │   └── src/                ← 템플릿 소스 코드 (필수)
  │
  ├── 2/
  │   └── ...
  │
  └── {n}/
      └── ...
```

### metadata.json 스키마

```json
{
  "id": 1,
  "title": "템플릿 이름",
  "description": "템플릿 스타일 설명 (키워드 기반)",
  "link": "템플릿 원본 출처 URL"
}
```

## 4. Step별 상세 정의

### [진입] 콘텐츠 → 스타일 전환

**트리거**: `portfolio.json`의 `about.confirmed: true`

```
[AI] 포트폴리오에 들어갈 내용 정리가 모두 끝났습니다.
     이제 어떤 느낌의 포트폴리오로 만들지 정해볼게요.
```

---

### Step 1. Style Preference

| 항목 | 내용 |
|:-----|:-----|
| 목적 | 사용자 스타일 선호도 수집 |
| 필드 | stylePreference.userInput |
| 필수 여부 | 필수 |
| 완료 조건 | stylePreference.confirmed = true |

**대화 예시:**
```
[AI] 어떤 분위기의 포트폴리오를 원하시나요?
     편하게 말씀해주세요.

     • '깔끔하고 미니멀한 느낌'
     • '개발자스럽고 터미널 같은 느낌'
     • '따뜻하고 친근한 느낌'

     자유롭게 설명해주셔도 됩니다.

[사용자] 심플하고 깔끔했으면 좋겠어요. 너무 화려한 건 별로고,
        내용이 잘 읽히는 게 중요해요.

[AI] 네, 심플하고 가독성 중심의 스타일이시군요.
     어울리는 템플릿을 찾아볼게요.
```

**상태 변경:**
```
stylePreference.userInput = "심플하고 깔끔했으면 좋겠어요..."
stylePreference.confirmed = true
```

---

### Step 2. Template Selection

| 항목 | 내용 |
|:-----|:-----|
| 목적 | LLM-as-a-Judge 기반 템플릿 추천 및 선택 |
| 필드 | selectedTemplate (templateId, title, description) |
| 필수 여부 | 필수 |
| 완료 조건 | selectedTemplate.confirmed = true |

**처리 로직:**
1. 전체 템플릿의 metadata.json 로드
2. 사용자 평문 ↔ 각 템플릿 description 비교 (LLM-as-a-Judge)
3. 가장 적합한 템플릿 선정

**대화 예시:**
```
[AI] 말씀하신 스타일과 어울리는 템플릿을 찾았어요.

     ┌─────────────────────────────────────┐
     │                                     │
     │  [preview.png 표시]                 │
     │                                     │
     │  [preview.gif 표시 (있을 경우)]      │
     │                                     │
     │  {title}                            │
     │  {description}                      │
     │                                     │
     └─────────────────────────────────────┘

     이 스타일 어떠세요?

     [이걸로 할게요]  [다른 거 볼래요]
```

**분기 처리:**

| 선택 | 동작 |
|:-----|:-----|
| "이걸로 할게요" | selectedTemplate.confirmed = true → Step 3 이동 |
| "다른 거 볼래요" | history에 기록 추가 → Step 1로 복귀 |

**"다른 거 볼래요" 선택 시:**
```
[AI] 알겠습니다. 어떤 스타일을 원하시는지 다시 말씀해주세요.
     조금 더 구체적으로 설명해주시면 더 잘 찾아드릴게요.
```

**상태 변경 (확정 시):**
```
selectedTemplate.templateId = "template-1"
selectedTemplate.title = "Minimal Clean"
selectedTemplate.description = "깔끔하고 미니멀한 디자인..."
selectedTemplate.confirmed = true
meta.status = "complete"
```

### Step 3. Generation

| 항목 | 내용 |
|:-----|:-----|
| 목적 | 템플릿을 사용자 디렉토리에 복사 |
| 전제 조건 | style.json의 meta.status = "complete" |
| LLM 사용 | **X** (파일 복사만) |

**대화 예시:**
```
[AI] {title} 템플릿으로 포트폴리오를 생성합니다.
     잠시만 기다려주세요.

     [로딩 인디케이터 표시]
```

**처리 흐름:**
```
┌─────────────────────────────────────────────────────────────────┐
│  입력                                                           │
│  • style.json → selectedTemplate.templateId                     │
│  • templates/{templateId}/src/                                  │
│  • data/{uuid}/portfolio.json, data/{uuid}/style.json           │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  처리 (LLM 없음, 파일 복사)                                      │
│  1. templates/{templateId}/src/ → data/{uuid}/src/ 복사         │
│  2. data/{uuid}/*.json → data/{uuid}/src/public/ 복사           │
│     • portfolio.json → src/public/portfolio.json                │
│     • style.json → src/public/style.json                        │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  결과                                                           │
│  • data/{uuid}/src/ 디렉토리 생성                               │
│  • 템플릿은 public/portfolio.json을 참조하여 렌더링              │
│    - Next.js: /portfolio.json (public 폴더 규칙)                │
│    - 정적 HTML: ./public/portfolio.json                         │
└─────────────────────────────────────────────────────────────────┘
```

### Step 4. Delivery

| 항목 | 내용 |
|:-----|:-----|
| 목적 | README.md 표시로 추가 작업 안내 및 시나리오 완결 |

**대화 예시:**
```
[AI] 포트폴리오가 생성되었습니다!

     ┌─────────────────────────────────────┐
     │                                     │
     │  [README.md 내용 표시]              │
     │                                     │
     │  예시:                              │
     │  # 포트폴리오 생성 완료              │
     │                                     │
     │  ## 추가 작업                       │
     │  다음 이미지를 추가해주세요:         │
     │  - profile.jpg (400x400)            │
     │                                     │
     └─────────────────────────────────────┘

     추가 작업이 필요하면 위 안내를 따라주세요.
     작업 완료 후 src/ 폴더를 실행하시면 됩니다.
```

**README.md 표시 규칙:**

| 상황 | 표시 내용 |
|:-----|:-----|
| 추가 이미지 필요 없음 | "별도 작업 없이 바로 사용 가능합니다." |
| 추가 이미지 필요 | 필요한 이미지 목록 (파일명, 용도, 권장 크기) |

**시나리오 완결:**

```
사용자에게 README.md 표시 → 시나리오 종료
```

> **Note**: 이후 사용자가 추가 이미지를 넣고 src/를 실행하면 포트폴리오 완성

## 5. 완성도 검증 로직

### 5.1 개요

각 Step에서 사용자 입력이 완료되었는지 검증하고, 미완성 시 재질문을 통해 정보를 수집합니다.

### 5.2 검증 플로우

```
┌─────────────────────────────────────────────────────────────────┐
│                    Step 1 완성 점검                              │
├─────────────────────────────────────────────────────────────────┤
│  사용자 스타일 입력 수신                                         │
│           ↓                                                     │
│  입력 내용 유효성 판단 (너무 짧거나 모호한지)                     │
│           ↓                                                     │
│  ┌───────┴───────┐                                             │
│  ↓               ↓                                             │
│ 유효           무효/모호                                        │
│  ↓               ↓                                             │
│ confirmed:    보조 질문                                         │
│ true 설정     "조금 더 구체적으로 설명해주세요"                  │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                    Step 2 완성 점검                              │
├─────────────────────────────────────────────────────────────────┤
│  템플릿 추천 후 사용자 선택 수신                                  │
│           ↓                                                     │
│  ┌───────┴───────┐                                             │
│  ↓               ↓                                             │
│ "이걸로"      "다른 거"                                         │
│  ↓               ↓                                             │
│ confirmed:    Step 1로 복귀                                     │
│ true 설정     (confirmed: false 유지)                           │
└─────────────────────────────────────────────────────────────────┘
```

### 5.3 모호한 입력 처리

**모호한 입력 예시:**
- "그냥 예쁘게요"
- "아무거나요"
- "잘 모르겠어요"

**대응:**
```
[사용자] 그냥 예쁘게요

[AI] 조금 더 구체적으로 여쭤볼게요.
     
     • 밝은 느낌과 어두운 느낌 중 어떤 게 좋으세요?
     • 움직이는 효과가 있는 게 좋을까요, 없는 게 좋을까요?
```

## 6. 주제 이탈 감지 로직

### 6.1 개요

스타일 질의와 무관한 주제 이탈을 감지하고, 대화를 원래 문맥으로 복귀시킵니다.

### 6.2 감지 대상

- 현재 Step과 무관한 질문
- 포트폴리오 스타일과 관련 없는 잡담
- 시스템 우회 시도

### 6.3 대응 방식

```
[사용자] 오늘 날씨 어때요?

[AI] 해당 질문에는 답변드리기 어렵습니다.
     현재 포트폴리오 스타일을 선택하는 중입니다.
     어떤 분위기의 포트폴리오를 원하시나요?
```

```
[사용자] 내 프로젝트 설명 수정하고 싶어

[AI] 네, 내용 수정을 원하시는군요.
     스타일 선택을 완료한 후에 수정하실 수 있어요.
     
     먼저 포트폴리오 스타일을 정해볼까요?
     어떤 분위기를 원하시나요?
```

| Step 2. Template Selection | O | LLM-as-a-Judge로 매칭 |
| Step 3. Generation | **X** | 파일 복사만 |
| Step 4. Delivery | X | 결과 제공만 |

## 8. UI 표시 요소 정리

### 스타일 질의 단계 (Step 1~2)

| 요소 | 필수 | 설명 |
|:-----|:-----|:-----|
| preview.png | O | 템플릿 정적 미리보기 |
| preview.gif | X | 인터랙션/스크롤 동적 미리보기 (있을 경우 표시) |
| title | O | metadata.json의 title |
| description | O | metadata.json의 description |
| 선택 버튼 | O | "이걸로 할게요" / "다른 거 볼래요" |

### 생성 단계 (Step 3~4)

| 요소 | 설명 |
|:-----|:-----|
| 로딩 인디케이터 | 생성 중 표시 |
| 미리보기 영역 | 완성된 포트폴리오 렌더링 |
| 미리보기 버튼 | 새 탭에서 전체 화면 확인 |
| 다운로드 버튼 | 소스 파일 압축 다운로드 |
| 후속 액션 버튼 | 내용 수정 / 스타일 변경 / 완료 |
