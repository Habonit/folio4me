## folio4me 프론트엔드 명세서

---

### 1. 서비스 개요

| 항목 | 내용 |
|:-----|:-----|
| 서비스명 | folio4me |
| 목적 | 질의응답 기반 포트폴리오 웹페이지 자동 생성 |
| 핵심 기능 | 챗봇 대화를 통해 콘텐츠 수집 → 템플릿 선택 → 포트폴리오 생성 |

**서비스 3단계 파이프라인**

```
[1단계] 콘텐츠 수집
   - 챗봇 질의응답으로 포트폴리오에 들어갈 내용 추출
   - 경력, 프로젝트, 기술 스택, 자기소개 등

[2단계] 형태/스타일 수집  
   - 레이아웃, 톤앤매너, 강조 요소 선택
   - 템플릿 선택

[3단계] 포트폴리오 생성
   - 수집된 콘텐츠 + 선택된 템플릿 결합
   - 최종 결과물 생성 및 다운로드
```

---

### 2. 화면 구성

| ID | 화면명 | 타입 | 설명 |
|:---|:-------|:-----|:-----|
| A | Login | 단독 | 로그인 화면 |
| B | Sign up | 단독 | 회원가입 화면 |
| C | Main (Board) | 사이드바 레이아웃 | 프로젝트 게시판 |
| D | Chat (Single) | 사이드바 레이아웃 | 전체 화면 채팅 |
| E | Chat (Split) | 사이드바 레이아웃 | 채팅 + 마크다운 분할 |
| F | API Key Modal | 모달 | OpenAI API Key 입력 |

---

### 3. 화면 흐름도

```
[A] Login
 ├─ 로그인 성공 → [C] Main
 └─ Sign up 클릭 → [B] Sign up → 가입 완료 → [A] Login

[C] Main (Board)
 ├─ 로그아웃 클릭 → [A] Login
 ├─ 설정 클릭 → [F] API Key Modal
 ├─ 로고 클릭 → [C] Main (현재 유지)
 └─ 게시글 클릭 → [D] Chat (Single)

[D] Chat (Single)
 ├─ 사이드바: 내용 추출 / 템플릿 선택 / 생성 탭
 └─ Step 진행 시 → [E] Chat (Split)

[E] Chat (Split)
 ├─ 좌측: 챗봇 대화
 └─ 우측: Step별 추출 결과 마크다운 렌더링
```

### 4. 화면별 상세 명세

#### 4.1 Login (A)

```
┌────────────────────────────────┐
│                                │
│         ┌──────────┐           │
│         │  Login   │           │
│         ├──────────┤           │
│         │ Username │           │
│         │ [      ] │           │
│         │ Password │           │
│         │ [      ] │           │
│         │                      │
│         │ Forgot password?     │
│         │ Contact your admin.  │
│         │                      │
│         │ [Sign in] [Sign up]  │
│         └──────────┘           │
│                                │
└────────────────────────────────┘
```

**기능**

| 요소 | 동작 |
|:-----|:-----|
| Username 입력 | 사용자 ID 입력 |
| Password 입력 | 비밀번호 입력 |
| Sign in 버튼 | 로그인 → C 이동 |
| Sign up 버튼 | B 화면 이동 |

#### 4.3 Main - Board (C)

**레이아웃**
```
┌─────────────────────────────────────────────┐
│ [Sidebar]                      [Logout]     │
│ ┌────────┐  ┌─────────────────────────────┐ │
│ │ Logo   │  │      Board Header           │ │
│ │        │  │  [+ Create]  [Delete]       │ │
│ │        │  ├─────────────────────────────┤ │
│ │        │  │ □ │ Title    │ Status │ Date│ │
│ │        │  │ □ │ Title    │ Status │ Date│ │
│ │        │  │ □ │ Title    │ Status │ Date│ │
│ │        │  │                             │ │
│ │        │  │                             │ │
│ │        │  │                             │ │
│ │ 설정   │  │                             │ │
│ └────────┘  └─────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

**사이드바**

| 위치 | 요소 | 동작 |
|:-----|:-----|:-----|
| 상단 | Logo | 클릭 시 C 유지 |
| 하단 | 설정 | 클릭 시 F (모달) 표시 |

**게시판**

| 요소 | 설명 |
|:-----|:-----|
| Create 버튼 | 새 게시글 생성 |
| Delete 버튼 | 선택된 항목 삭제 |
| Checkbox | 삭제할 항목 선택 |
| Title | 기본값: `{userid}의 포트폴리오`, 우클릭으로 수정 가능 |
| Status | 진행률 표시, 초기값 `0%` |
| Date | 생성일자 자동 기록 |
| Row 클릭 | D 화면 이동 |

**헤더**

| 요소 | 동작 |
|:-----|:-----|
| Logout 버튼 | 로그아웃 → A 이동 |

#### 4.4 Chat - Single (D)

**레이아웃**
```
┌──────────────────────────────────────────────┐
│ [Sidebar]                       [Logout]     │
│ ┌─────────────┐ ┌──────────────────────────┐ │
│ │ Logo        │ │                          │ │
│ ├─────────────┤ │                          │ │
│ │ 📁 내용 추출 │ │                          │ │
│ │   ├ Step 1  │ │       Chat Area          │ │
│ │   ├ Step 2  │ │                          │ │
│ │   └ Step 3  │ │                          │ │
│ ├─────────────┤ │                          │ │
│ │ 🎨 템플릿   │ │                          │ │
│ │   ├ Step 1  │ │                          │ │
│ │   └ Step 2  │ │                          │ │
│ ├─────────────┤ │  ┌────────────┐ ┌──────┐ │ │
│ │ 🚀 생성     │ │  │ Input...   │ │ Send │ │ │
│ │   └ Step 1  │ │  └────────────┘ └──────┘ │ │
│ ├─────────────┤ └──────────────────────────┘ │
│ │ 설정        │                              │
│ └─────────────┘                              │
└──────────────────────────────────────────────┘
```

**사이드바 탭**

| 탭 | 설명 | Steps |
|:---|:-----|:------|
| 포트폴리오 내용 추출 | 콘텐츠 수집 단계 | Step 1, 2, 3... |
| 포트폴리오 템플릿 선택 | 형태/스타일 선택 | Step 1, 2... |
| 포트폴리오 생성 | 최종 생성 | Step 1... |

**채팅 영역**

| 요소 | 설명 |
|:-----|:-----|
| Chat Area | 대화 내역 표시 (사용자/봇 구분) |
| Input | 메시지 입력창 |
| Send 버튼 | 메시지 전송 |
